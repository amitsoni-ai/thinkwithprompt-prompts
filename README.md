# ThinkWithPrompt AI Prompt Library

2,663 curated, ready-to-use AI prompt templates for ChatGPT, Claude, Gemini and other assistants, selected, edited and reviewed by the ThinkWithPrompt editorial team at Synottic. Each prompt is a template with fill-in blanks in [BRACKETS] and follows a named prompt framework (RTF, RCTF, RCTFVV, Few-Shot, Chain-of-Thought and others).

Browse, search and fill in the prompts at **[thinkwithprompt.com](https://www.thinkwithprompt.com)**. Every row links to its page.

## Files

- `prompts.jsonl`: one prompt per line.
- `prompts.csv`: the same data as CSV (lists joined with "; ").

## Fields

| Field | Description |
|---|---|
| id | Stable numeric id |
| title | What the prompt does |
| description | One-line summary |
| prompt | The prompt template; blanks are in [BRACKETS] |
| category | Topic (28 topics) |
| framework | Prompt structure used (Few-Shot, RTF, RCTFVV, RCTF, Zero-Shot, Chain-of-Thought, RISEN) |
| level | Standard or Advanced |
| type | TEXT, IMAGE or VIDEO |
| tags | Task and audience tags |
| variables | The blanks to fill in |
| url | The prompt's page on thinkwithprompt.com |

## Provenance

Most prompts were written or rewritten by the ThinkWithPrompt team. The library's starting point included the public-domain (CC0) [awesome-chatgpt-prompts](https://github.com/f/awesome-chatgpt-prompts) collection, whose prompts were reviewed, restructured into prompt frameworks, merged or removed; see [how we curate](https://www.thinkwithprompt.com/about/how-we-curate).

Prompts are provided as is, without warranty. Outputs from AI models can be wrong; review anything you rely on.
